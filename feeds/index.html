Deployment examples

Reference commands for common environments. Use the feed format above and schedule refreshes on the same six-hour cadence.

$ curl -sS https://neilweitzel.github.io/xfeeds/iptables.ipset | sudo ipset restore -! $ sudo iptables -I INPUT -m set --match-set xfeeds src -j DROP

Loads the IPv4 high-confidence feed, then drops matches. Add the first line to cron every six hours.

$ curl -sS -o xfeeds.nft https://neilweitzel.github.io/xfeeds/nftables.conf $ sudo nft -f xfeeds.nft

Creates IPv4 and IPv6 sets. Reference @blocklist4 or @blocklist6 in your ruleset.

Firewall → Aliases → Add Type: URL Table (IPs) URL: https://neilweitzel.github.io/xfeeds/high-confidence.txt Update frequency: 1 day

Create a WAN block rule using this alias. The combined list contains both families.

/tool fetch url="https://neilweitzel.github.io/xfeeds/high-confidence.txt" dst-path=xfeeds.txt /import file-name=xfeeds.txt

Use an address list with a scheduled script. Strip # comments before importing.

curl -sS https://neilweitzel.github.io/xfeeds/high-confidence.txt | grep -v '^#' > xfeeds.txt # Account → Configurations → Lists → upload xfeeds.txt

About the project

What xfeeds is, and why it exists.

xfeeds is a public, corroborated malicious-IP feed. Every published record is backed by at least one high-precision source or by two independent classes of evidence — not by the number of source files that happen to repeat it. Widely-scoped prefixes and known cloud, CDN, and resolver space are held back rather than published as blocks.

The corpus draws on 24 sources across 13 independent evidence classes, refreshed every six hours.

Why it matters

An open, auditable alternative to opaque blocklists.

Commercial blocklists rarely publish the evidence behind a record. xfeeds does: the analysis surface shows the publication funnel, the corroboration histogram, per-source health, and the IPv4 address-space distribution, so a security team can decide for themselves what to trust.

Everything is generated from committed artifacts, hosted on GitHub Pages, and reproducible from source.

Two licence tiers. The primary tier is for any use, including commercial work. The non-commercial tier is CC BY-NC-SA 4.0 and can carry more share-alike material.

Spamhaus attribution travels with the data. Threat data is also provided by IPThreat at ipthreat.net and the Turris Sentinel project at CZ.NIC (CC BY-NC-SA 4.0, non-commercial tier only).

Network attribution in analysis: IPtoASN by Frank Denis (Public Domain, PDDL v1.0). It maps networks; it contributes no threat data.

Think an address is wrong? Report a false positive. Confirmed mistakes are permanently allowlisted.
